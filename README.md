# Oracle — battle autopsy site

Static site for viewing hindsight battle reports in a browser. No build step,
no server, no dependencies.

## Structure

```
index.html              Landing / program selector
scryer.html             Project Haruspex archive
heimdall-battles.html   Project Heimdall battle selector
heimdall.html           Project Heimdall world-map replay
heimdall.js      Canvas renderer, timeline, map interaction and filters
heimdall.css     Replay-specific responsive styles
heimdall-battles.css    Battle-selector styles
styles.css       Shared shell styles
tools/           Offline replay-data converter
data/heimdall/   Generated static replay manifest and event chunks
reports/         Self-contained reports generated by hindsight (--html)
```

The pages in `reports/` are fully self-contained and do not use `styles.css`.

## Update the Heimdall replay

Convert a watcher NDJSON export before publishing:

```powershell
python tools/convert_replay.py C:\path\to\capture.ndjson data\heimdall\battle-id
```

The converter keeps marches (including speed in tiles per second), direction updates, march deletions and a
player-aware base timeline. Only map entity type 6 is treated as a player;
generic `remove` messages for mines, farms, rubble and other entities cannot
move a base. Changing map-point IDs are merged into logical players, and a
march-derived base is emitted only when a later point update confirms it.

Add the battle metadata to `data/heimdall/battles.json` so it appears in the
selector. Alongside compact five-minute chunks, conversion writes a
`diagnostics.json` inside the battle directory with identity coverage, relocation pairing,
3x3-overlap corrections and unresolved march owners. Preview through an HTTP
server rather than opening the HTML as a `file://` URL:

```powershell
python -m http.server 8000
```

## Add a report

1. On your PC, generate the page:
   ```
   python -m hindsight battles/REPORT.json --html
   ```
2. Copy the generated `.html` into `reports/`.
3. Add one line to the `REPORTS` array near the bottom of `scryer.html`:
   ```js
   { title: "Battle Autopsy — <name>", date: "2026-08-06",
     file: "reports/<file>.html", note: "5v5 · 42s" },
   ```
   Newest first. `note` is optional.
4. Commit + push (or re-upload the changed files).

→ Deploy from a branch → `main` / root**. The site goes live at
`https://<user>.github.io/<repo>/` within a minute.
